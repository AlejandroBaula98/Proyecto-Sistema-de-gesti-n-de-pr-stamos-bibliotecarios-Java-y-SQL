# Proyecto-Sistema-de-gesti-n-de-pr-stamos-bibliotecarios-Java-y-SQL
Proyecto académico de escritorio desarrollado con Java Swing y arquitectura MVC, conectado a una base de datos MariaDB. Incluye acceso por roles, búsqueda de libros, registro de préstamos y devoluciones, consulta de multas y alertas de vencimiento.
